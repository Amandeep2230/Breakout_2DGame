# 🧱 Breakout Game (Go + Raylib)

A modern remake of the classic **Breakout** arcade game developed using **GoLang** and the **Raylib** game development library. This project was built as a personal learning exercise to explore the fundamentals of 2D game development.

![breakout](https://github.com/user-attachments/assets/0e101f6e-8eaf-4311-8e81-1e9d09ae5aad)


## 🎮 About the Game

Breakout is a single-player paddle and ball game where the player controls a paddle to bounce a ball against a wall of bricks. The objective is to break all the bricks without letting the ball fall below the paddle.

## ⚙️ Technologies Used

- **GoLang** – Fast, efficient programming language great for performance-critical applications
- **Raylib** – A simple and easy-to-use library for game development

## 🧠 Learning Outcomes

This project helped me:

- Gain **extensive experience with data structures** for handling game elements
- Understand **game physics** and **element interactions** (ball, paddle, bricks)
- Handle **collision detection** and **game mechanics** efficiently
- Learn how to **structure a 2D game** from the ground up
- Discover the **power of GoLang** in real-time graphics and game loops

## 🧩 Challenges Faced

- Managing **complex boundary conditions** for collisions
- Setting up the **initial game scene**, props, and layout
- Keeping gameplay smooth while managing multiple interactions per frame

## 📦 Future Improvements
